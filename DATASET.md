# Dataset provenance

The workbook in `datasets/` was supplied for the internship assignment.
Its content hash is recorded in `outputs/run.json` and `outputs/advanced/summary.json`.
The original workbook is never modified. Redistribution permission has not been
established, so raw workbooks are excluded by `.gitignore`. Before a public release,
confirm the source license and provide an authorized download link. Tests requiring
the original data run locally; CI smoke checks do not require redistribution.
